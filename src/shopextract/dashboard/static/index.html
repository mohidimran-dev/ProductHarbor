How a collection run works

One path from URL to export — with a human gate only when the storefront requires it.

  1. Paste a collection URL Choose Auto, Shopify, WooCommerce, or Custom, then pick Test (5) or Full (up to 1000).
  2. Start the job ProductHarbor detects the platform path and begins discovery against the public storefront.
  3. Clear gates if needed In interactive mode, complete CAPTCHA or login in the visible browser, then press Continue.
  4. Review and download Inspect live preview and product cards, then export JSON when the run retains products.
